# 取消进行中的任务

## 何时触发

当用户表达停止当前生成/任务的意图，且**当前会话存在** `queued` 或 `running` 的 task 时，走取消路径（与桌面「停止」按钮相同）：

- 短指令：`停`、`停止`、`停下`、`取消`、`中断`、`别说了`、`不要了`
- 英文：`stop`、`cancel`、`abort`（可带感叹号/句号）

实现：`POST /v1/tasks/:id/cancel` → DB `cancelTask` → worker 协作退出 → SSE `task.cancelled`。

## 何时不要触发

- 句子里只是提到「停止」「取消」但并非指令（如「停止呼吸法是什么」）
- 当前会话没有进行中的任务：当作普通消息发送

## 约定

- 自然语言与 UI 停止按钮必须调用同一 `cancelTask` API
- 取消后不落库半截 assistant 消息；流式草稿可保留在客户端直到刷新
